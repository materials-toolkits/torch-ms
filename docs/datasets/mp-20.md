# MP-20

Structures of the Materials Project with at most 20 atoms per cell, as released with CDVAE.

| Split | Structures |
|---|---|
| `train` | 27,136 |
| `val` | 9,047 |
| `test` | 9,046 |
| total | 45,229 |

The CDVAE paper reports 45,231 structures; the released files hold 45,229, all of them here.

```python
dataset = load_dataset("mp-20", "train")
```

## Labels

| Field | Source column |
|---|---|
| `formation_energy_per_atom` | `formation_energy_per_atom` |
| `energy_above_hull` | `e_above_hull` |
| `band_gap` | `band_gap` |
| `total_energy` | – (`NaN`) |

The energy above the hull is at most 0.08 eV/atom: the dataset only holds stable and
meta-stable structures. The space group number of the source is not stored.

## Filters

**No filter is needed**: the dataset was already selected (at most 20 atoms, at most
0.08 eV/atom above the hull) and every structure has its three labels.

```python
from torchms.data import Filter, load_dataset

dataset = load_dataset("mp-20", "train")                   # recommended: everything
stable = load_dataset("mp-20", "train", filter=Filter(max_energy_above_hull=0.0))
```

| Filter | Keeps, of `train` / `val` / `test` |
|---|---|
| none | 27,136 / 9,047 / 9,046 |
| `Filter(max_energy_above_hull=0.0)`, on the hull | 11,958 / 4,130 / 4,127 |
| `Filter(exclude_elements=(2, 10, 18, 36, 54, 86))`, without noble gases | 27,117 / 9,041 / 9,042 |

Filtering changes the splits of the benchmark: results are then not comparable with the ones
published on MP-20.

See [Filtering a dataset](../guide/datasets.md#filtering-a-dataset) for every setting.
