# MP-20

Structures of the Materials Project with at most 20 atoms per cell, as released with CDVAE.

| Split | Structures |
|---|---|
| `train` | 27,136 |
| `val` | 9,047 |
| `test` | 9,046 |
| total | 45,229 |

The CDVAE paper reports 45,231 structures; the released files hold 45,229, all of them here.

```python
dataset = load_dataset("mp-20", "train")
```

## Labels

| Field | Source column |
|---|---|
| `formation_energy_per_atom` | `formation_energy_per_atom` |
| `energy_above_hull` | `e_above_hull` |
| `band_gap` | `band_gap` |
| `total_energy` | – (`NaN`) |

The energy above the hull is at most 0.08 eV/atom: the dataset only holds stable and
meta-stable structures. The space group number of the source is not stored.
