# PyCrystalGen

## Setup with uv

### Installation on linux and macOS

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Alternative with `pip`:
```bash
pip install uv
```

### Add dependancies

```bash
uv add 'requests==2.31.0'
```

### Run

Run `python main.py` inside uv's virtual env.
```bash
uv run python main.py
```
